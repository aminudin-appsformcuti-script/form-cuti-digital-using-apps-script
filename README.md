# form-cuti-digital-using-apps-script
Form cuti digital using apps script for internal 

🚀 Transformasi Proses Pengajuan Cuti: Dari Manual ke Digital!
Pengajuan cuti menggunakan kertas atau pesan singkat sering kali memicu penumpukan administrasi dan risiko miss-communication. 
Untuk menjawab tantangan tersebut, saya mengembangkan proyek Form Cuti Digital. 
System ini dirancang untuk mempermudah karyawan mengajukan cuti sekaligus membantu Atasan memantau dan menyetujui pengajuan secara real-time.

🔍 Problem & Solution:
Mengubah alur pengajuan cuti konvensional yang berbelit-belit menjadi alur digital 3 langkah mudah: 
Isi Form ➡️ Kirim ➡️ Pantau Status Approval.

🎯 Highlights:
- Tampilan clean & mobile-friendly.
- Sistem status transparan dan real-time.
- Database tersimpan rapih.

✨ Fitur Utama:
- Paperless Request: Form pengajuan simpel dan terstruktur tanpa menggunakan kertas.
- Approval Workflow: Notifikasi dan persetujuan langsung dari atasan
- Tracker apps : Karyawan bisa memantau status cuti nya menggunakan app tracker khusus.

🛠️ Tech Stack: 
- Code menggunakan App Script dan HTML
- Database menggunakan Google Spreadsheet terintergrasi dengan Gdrive untuk menyimpan file .pdf dan file evidence photo
